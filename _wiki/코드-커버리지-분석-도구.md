# test coverage란?

- test suite를 통해 프로그램이나 코드가 얼마나 실행되는가를 의미한다.

### 측정 기준

1. Statement
  line coverage라고도 한다. 실행된 코드의 라인 수로 퍼센테지를 계산한다.
  ~예시 추가 예정~ 
2. Condition
  모든 조건식의 모든 조건이 true/false를 가지는가를 측정한다.
  ~예시 추가 예정~ 
3. Decision
  branch coverage라고도 한다.
  모든 조건식이 true/false를 가지는가를 측정한다.
  
  
# 어떤 도구를 사용할 것인가?

Java code coverage tool 중 Cover, Jacoco 등이 있는데 빠른 도입과 쉬운 사용이 목적이므로 레퍼런스가 많은 Jacoco로 결정
